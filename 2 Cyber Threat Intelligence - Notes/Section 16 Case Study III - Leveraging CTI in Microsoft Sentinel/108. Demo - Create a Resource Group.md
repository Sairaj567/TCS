## Detailed Notes

### Lecture Flow

You learned everything about the Azure resource hierarchy earlier and also about the deployment prerequisites for [[2 Cyber Threat Intelligence - Notes/Section 16 Case Study III - Leveraging CTI in Microsoft Sentinel/98. What is Microsoft Sentinel|Sentinel]].
But what we are going to do now is we will actually fulfill one of those prerequisites, which is having an [[1 Cybersecurity Foundation - Notes/5 – Data Security and Encryption|Azure]] resource group.
let's actually create one by clicking on resource groups.
And then you click on create.

### Then you select a subscription

Then you select a [[2 Cyber Threat Intelligence - Notes/Section 3 AZURE/16. Azure Subscription Types|subscription]].
In my case I go with the demo subscription and we provide a name for the resource group.
You can actually also opt in with a different region, than US East one.
for me this is fine, but feel free to change it if you want to.

### The text is something that you can actually leave open, and then we clic

The text is something that you can actually leave open, and then we click on next.
And then after the validation has passed we can click on create.
And after a few seconds you see the resource group is being provisioned.
That is also, by the way, the list of all resource groups that you have in the respective subscription.
and if you go on the resource group, you can actually see the attributes associated with it.
