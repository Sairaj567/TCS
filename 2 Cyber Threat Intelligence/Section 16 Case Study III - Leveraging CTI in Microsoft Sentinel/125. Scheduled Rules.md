What are scheduled rules?

They are basically analytic rules that continuously run in a defined time frame, meaning you can define

a time frame from, let's say, of at minimum five minutes up to 14 days.

And you can then say, I want my scheduled rule to run every hour and have a lookback period of like

an hour.

It can even be longer or less than an hour.

And then the rule will run and fire an alert if a certain condition is met.

Keep in mind that scheduled rules are the default rule.

Type in Sentinel, and that actually what I see is that most organizations have the analytic rules based

on scheduled rule type.

This is also due to certain limitations in Sentinel.

For example, for certain rule types you can only have one rule or 50 rules that highly depends on the

rule type.

Scheduled rules are unlimited, which is why they are also the default rule type for most use cases.
